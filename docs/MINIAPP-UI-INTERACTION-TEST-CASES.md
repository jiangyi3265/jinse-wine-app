# 金色酒业小程序页面展示与交互测试文案

> 用途：给测试、产品、运营和联调人员使用的逐页点检脚本。每条用例都要记录“通过 / 失败 / 阻塞”，失败必须附页面截图、操作路径、接口响应和复现时间。

## 开始点检前需要准备什么

### 最低准备（本机页面联调）

- [ ] MySQL 已启动在 `3307`，业务库、系统表、营销表、内容表和后台菜单迁移已导入。
- [ ] Redis 已启动，Java 服务可访问 `http://127.0.0.1:8080`。
- [ ] 后台前端可访问 `http://localhost`；已有管理员账号 `admin` 可登录。
- [ ] 微信开发者工具已打开项目 `D:\project_team\酒\jinse-wine-app\unpackage\dist\build\mp-weixin`，不要用 H5 页面代替小程序点检。
- [ ] 后台和小程序都使用同一套数据库数据；测试期间不要同时修改同一条商品、券或内容记录。

### 完整业务点检必须准备

- [ ] 一个普通用户测试身份：能进入小程序并完成登录，至少有一条地址、一个可用优惠券、足够积分和一笔可测试订单。
- [ ] 一个核销员测试身份：`biz_member.staff_store_id` 已绑定门店，可进入门店核销页；普通用户只能验证“暂无核销权限”分支。
- [ ] 一组订单数据：待付款、待发货、待收货、已完成、已取消各至少一条，并准备一个不存在的订单 ID。
- [ ] 一组奖励数据：待兑换奖品、已兑换奖品、有效兑换码、已核销兑换码、过期/无效兑换码各至少一条。
- [ ] 一组券数据：可用券、已使用券、已过期券、门槛不足券、数量不足券、会员限制券各至少一条。
- [ ] 一组边界库存：正常库存、库存为 1、库存为 0；至少准备一个积分不足和一个重复兑换场景。
- [ ] 门店测试字段：至少一条有电话/经纬度/二维码，一条故意缺少电话或经纬度，用于验证失败提示。

### 真机和微信能力点检（可选，但上线前必须准备）

- [ ] 小程序 AppID、AppSecret：用于真实微信登录；密钥只放本机配置，不要粘贴到聊天。
- [ ] 微信支付商户号、API v3 密钥、商户私钥/证书、公网 HTTPS 回调地址：用于真实支付和支付回调。
- [ ] 现金红包相关商户配置和回调地址：用于真实红包领取。
- [ ] 一台已登录微信的真机，与服务端处于同一可访问网络；真机环境不能使用 `127.0.0.1`，需改为局域网 HTTPS 地址。
- [ ] 相机、定位、电话、客服、保存图片、分享等微信权限；扫码、地图、支付、客服和保存海报必须在真机复测。

### 目前没有这些配置时能测什么

- 可以完整点检页面展示、后台回显、搜索筛选、表单校验、空状态、接口 401/404/409/500、库存/幂等和所有演示失败分支。
- 真实微信登录、真实支付、现金红包、扫码相机、地图导航、电话、客服、保存海报只能验证入口和明确失败提示，不能标记为“真实成功通过”。

## 一、测试范围与执行约定

### 1. 环境

- 运行端：微信开发者工具，小程序构建目录 `unpackage/dist/build/mp-weixin`。
- 服务端：Java `http://127.0.0.1:8080`，后台管理 `http://localhost`，MySQL 端口 `3307`。
- 测试模式：联调包默认 API 模式；没有微信 AppSecret、支付商户号和公网回调时，登录、支付、红包必须验证“配置缺失”的失败提示，不得伪造成功。
- 页面原则：页面视觉、颜色、图片比例和文案层级不因测试而修改；测试只验证数据是否来自后台、交互是否符合预期。

### 2. 基准数据

| 数据 | 预期值 |
| --- | --- |
| 商品 | 4 条，至少包含“典藏酱香”，售价 398.00 元，划线价 498.00 元 |
| 门店 | 2 条，至少包含“金色酒业体验店”和“金色酒业合作门店” |
| 优惠券模板 | 4 条：节日券、社群券、满减券、积分代金券 |
| 兑换项 | 3 条：20 元代金券、品鉴杯、双杯礼盒 |
| 小程序内容 | 21 条，包含首页、活动、品牌图片和规则配置 |
| 后台菜单 | 商品、门店、优惠券、兑换、订单、会员、奖品、核销、品牌、小程序内容 |

### 3. 通用判定

每个页面都要检查以下内容：

1. 首屏标题、品牌名、返回按钮、底部 Tab、空状态和加载状态是否正确。
2. 所有文字不溢出、不截断、不出现 `undefined`、`null`、`NaN`、英文调试信息。
3. 所有图片都能加载；图片比例、裁剪、圆角和占位效果正常；图片地址来自后台配置或服务端媒体地址。
4. 连续点击按钮 2 次不会重复提交、重复扣库存、重复领券或重复生成订单。
5. 返回后状态保留：筛选条件、数量、地址、优惠券、已领取状态和订单状态不能被错误重置。
6. 断网、接口 401、接口 404、接口 500、空数组、字段为空时，页面显示可理解的中文提示，并且不崩溃。
7. 页面从分享、直达或带错误参数进入时，仍显示空状态或回到首页，不出现白屏。

## 二、逐页展示与交互用例

### TC-01 首页 `pages/index/index`

**展示检查文案**

> “检查首页品牌名、城市、主轮播、快捷入口、领券横幅、精选好酒、视频号入口和底部 Tab。确认标题、图片、价格、划线价、角标、轮播页码与后台配置一致。”

**正常操作**

1. 首次进入首页，等待接口完成，确认轮播图、商品图和运营图片全部出现。
2. 左右滑动轮播图，确认图片、标题、页码和进度条同步变化；快速连续滑动后仍停在合法页。
3. 点击城市，进入“兑换网点”；返回首页后首页数据和滚动位置不出现错乱。
4. 点击轮播文案或精选商品，进入对应商品详情；点击“全部”，进入商城。
5. 依次点击扫码有礼、兑换网点、积分专区、VIP 社群、节日领券、视频号精选，确认路由和页面标题正确。
6. 点击领券横幅，进入中秋活动；点击底部“首页 / 商城 / 扫码 / 推广 / 我的”，确认 Tab 高亮和页面切换正确。

**异常操作**

- 商品接口返回空数组：显示“暂无商品数据”或空状态，不能显示假商品价格。
- 内容接口返回空图片或错误地址：显示占位，不显示破图图标。
- 首页接口超时：保留页面骨架并提示“网络连接失败，请检查服务地址或网络”。
- 快速重复点击轮播和入口：不能叠加打开多个相同页面。

### TC-02 商城 `pages/shop/index`

**展示检查文案**

> “检查搜索框、分类 Tab、综合/销量/价格排序、商品卡片、图片、售价、划线价和空结果提示。”

**正常操作**

1. 输入“典藏”，确认只显示匹配商品；点击清空按钮，恢复全部商品。
2. 输入规格关键词“500mL”，确认名称、规格和分类均参与搜索。
3. 依次点击商品分类，确认分类高亮和商品列表更新。
4. 点击“综合”，确认恢复默认顺序；点击“销量”，确认销量降序。
5. 点击“价格”两次，确认价格升序、价格降序切换，箭头方向同步。
6. 点击商品卡片，进入商品详情；返回商城后搜索、分类和排序保持。

**异常操作**

- 输入不存在的关键词：显示“没有找到相关商品 / 换个关键词或分类再试试”。
- 输入前后空格、超长字符串、特殊字符：不崩溃，结果为空时走空状态。
- 接口返回商品缺少价格、图片或库存：页面不显示 `undefined`，购买按钮按库存状态处理。
- 接口失败：展示错误提示，不能把演示商品混入 API 模式。

### TC-03 商品详情 `pages/product/index`

**展示检查文案**

> “检查商品轮播图、商品名称、系列、规格、售价、划线价、优惠提示、配送说明、商品详情、客服入口和底部购买按钮。”

**正常操作**

1. 进入“典藏酱香”，左右滑动详情图片，点击图片验证预览图。
2. 点击“领券”，进入领券中心；返回后详情信息不丢失。
3. 点击“选择规格”，打开底部弹层；检查默认规格、单价和数量。
4. 点击减少：数量为 1 时按钮禁用；点击增加：数量不能超过库存。
5. 点击遮罩、关闭按钮和“确定”，确认弹层分别关闭并保留/确认数量。
6. 点击“配送说明”，进入规则页；点击“联系客服”，进入客服页。
7. 点击“立即购买”，进入确认订单，商品、规格、数量和金额一致。

**异常操作**

- 商品 ID 不存在、已下架或接口返回空：显示“商品不存在或已下架”，提供“去商城”。
- 库存为 0：购买按钮禁用或提示库存不足；不能创建订单。
- 快速连点增加和立即购买：数量和路由只提交一次。
- 图片加载失败：显示合法占位，不能影响价格和购买操作。

### TC-04 确认订单 `pages/checkout/index`

**展示检查文案**

> “检查收货地址、商品摘要、数量、商品金额、运费、优惠券、微信支付、合计、报价说明和提交订单按钮。”

**正常操作**

1. 从商品详情进入，确认商品、规格、数量和价格与上页一致。
2. 点击“请选择收货地址”，进入地址选择；选择地址后返回，姓名、脱敏手机号和地区正确回显。
3. 点击优惠券行，进入选择优惠券；选择可用券返回，券名称、优惠金额和合计更新。
4. 选择“不使用优惠券”，确认优惠金额归零。
5. 等待服务端报价完成，确认商品小计、运费、优惠、总计字段均为数字金额。
6. 点击“提交订单”，确认只创建一个订单并进入订单详情。

**异常操作**

- 未选择地址：点击提交，提示“请先填写收货地址”。
- 报价接口未完成或返回错误：提交按钮禁用，显示服务端原因。
- 优惠券过期、已使用、不满足门槛或数量要求：不能选中，显示不可用原因。
- 库存不足、价格变化、重复请求：订单不创建或只创建一笔，并显示明确错误。
- 连续点击提交：按钮进入“提交中…”，不得重复下单。
- 地址/券页面返回失败：回退到首页的兜底逻辑必须生效，不能白屏。

### TC-05 收货地址 `pages/addresses/index` 与地址编辑 `pages/address-edit/index`

**正常操作**

1. 从“我的”进入地址列表，确认默认地址标识、姓名、手机号、地区和详细地址。
2. 点击“新增收货地址”，依次填写姓名、手机号、所在地区、详细地址，切换默认开关并保存。
3. 从订单确认页进入选择模式，点击地址卡或“选择此地址”，确认回到订单页且地址已回显。
4. 点击“编辑地址”，修改字段后保存，确认列表和订单页同步更新。
5. 新增第二条默认地址，确认原默认地址取消默认标识。

**输入校验**

| 字段 | 正常 | 异常预期 |
| --- | --- | --- |
| 收货人 | 1~30 个字符 | 空值提示“请填写收货人姓名” |
| 手机号 | 11 位 `1[3-9]` 开头手机号 | 空值、非 11 位、非法号段提示“请填写正确的手机号码” |
| 所在地区 | 不超过 80 字 | 空值提示“请补全所在地区和详细地址” |
| 详细地址 | 不超过 180 字 | 空值提示“请补全所在地区和详细地址” |
| 默认开关 | 开/关各保存一次 | 回显值必须与保存结果一致 |

**异常操作**

- 只填一项直接保存：阻止提交，错误提示不丢失。
- 超过 maxlength 粘贴文本：输入框截断或拒绝超长内容，不能溢出页面。
- 保存接口 401/500：保留当前填写内容，提示失败，不返回列表。
- 地址列表为空：显示“还没有收货地址”，新增按钮仍可用。

### TC-06 领券中心/我的优惠券 `pages/coupons/index`、`pages/my-coupons/index`

**正常操作**

1. 领券中心检查“全部 / 节日活动 / 社群专享”筛选。
2. 点击“领取”，确认按钮变为“已领取”，再次点击不重复领取。
3. 点击“我的优惠券”，检查“未使用 / 已使用 / 已过期”筛选和状态颜色。
4. 点击优惠券规则，进入规则页；点击“去使用”，进入商城。
5. 从确认订单进入选择模式，检查“全部 / 可用 / 不可用”、不可用原因和“不使用优惠券”。
6. 选择优惠券返回订单，确认券 ID、适用商品、减免金额一致。

**异常操作**

- 重复领券、领券接口超时、券已下架：提示失败或“已领取”，不增加重复券。
- 不满足满减金额、数量、会员或商品限制：按钮禁用并显示具体原因。
- 已使用/已过期券点击使用：不能进入订单抵扣。
- 列表为空：显示空状态和正确的去领券入口。

### TC-07 中秋活动 `pages/campaign/index`

**正常操作**

1. 检查活动标题、主图、活动券、社群券、品牌公众号、视频号和活动规则。
2. 点击“领取优惠券”，确认领取成功提示和按钮状态。
3. 已领取状态点击按钮，直接进入我的优惠券。
4. 点击“查看活动”，进入社群优惠券筛选；点击公众号、视频号和活动规则，检查参数正确。

**异常操作**

- 后台未配置活动券：显示“暂无可领取活动券”，不产生空券。
- 后台未配置活动图片/视频号：显示占位或“品牌视频号尚未配置”。
- 重复领取和接口 500：不重复写入，保留页面状态。

### TC-08 积分专区 `pages/points/index`

**正常操作**

1. 检查积分余额、积分记录入口、“全部 / 优惠券 / 实物”筛选。
2. 点击代金券、品鉴杯、双杯礼盒的兑换按钮，确认积分扣减、库存扣减和结果页跳转。
3. 点击积分规则，检查规则类型参数；点击积分记录，检查记录列表。

**异常操作**

- 积分不足：提示余额不足，积分和库存不变化。
- 库存为 0、兑换项下架、重复点击：不能兑换或只成功一次。
- 接口超时：显示失败，不出现已兑换假状态。

### TC-09 扫码有礼 `pages/scan/index`

**正常操作**

1. 检查扫码按钮、奖励预览、规则和抽奖记录入口。
2. 在微信环境点击扫码，授权后扫描有效码，确认抽奖结果跳转到红包、积分、优惠券或奖品页。
3. 点击奖励预览卡片，确认对应页面和参数。
4. 从记录页打开一条奖励记录，确认能回到对应奖励详情。

**异常操作**

- 用户取消扫码：不提示错误、不发放奖励。
- 相机权限拒绝：提示“无法扫码，请检查相机权限”。
- 无效码、过期码、重复码：提示失败，不重复发奖。
- 抽奖接口 401/500：保留当前页面，不显示成功结果。

### TC-10 现金红包 `pages/redpacket/index`

**正常操作**

1. 检查红包金额、状态、领取按钮、记录入口和客服入口。
2. 使用有效红包领取一次，确认按钮状态、记录和余额展示一致。
3. 点击红包记录进入记录页；领取成功后点击“返回首页”。

**异常操作**

- 未登录：进入登录失败分支，不能领取。
- 红包已领取、已过期、不可领取：按钮禁用或显示明确原因。
- 微信官方红包未配置：服务端返回 503“现金红包服务尚未配置”类提示，不伪造到账。
- 连续点击领取：只产生一个领取请求。

### TC-11 兑换网点 `pages/stores/index` 与门店详情 `pages/store-detail/index`

**正常操作**

1. 检查地图图、城市筛选、门店名称、地址、营业时间、图片和距离。
2. 输入门店名或地址，确认过滤；点击城市切换全部、城市和区县。
3. 点击定位按钮，确认定位配置提示；点击门店二维码进入详情。
4. 门店详情检查二维码、地址、客服、门店社群、拨打电话和导航到店。
5. 从详情页返回，确认回到门店列表；错误门店 ID 显示“门店不存在”。

**异常操作**

- 搜索无结果：显示“没有找到门店 / 试试门店名称或切换区域”。
- 门店没有电话：提示“门店联系电话尚未配置”。
- 门店没有经纬度：提示“门店导航位置尚未配置”。
- 地图、二维码图片失败：显示占位，不阻断其他按钮。
- 直接打开详情无 ID：使用默认门店或空状态，不抛异常。

### TC-12 我的 `pages/profile/index`、个人资料 `pages/profile-edit/index`

**正常操作**

1. 检查头像、昵称、手机号脱敏、积分、优惠券、奖品、订单状态、VIP 和推广入口。
2. 点击头像/昵称进入个人资料；修改昵称并保存，确认返回后回显。
3. 依次点击积分、优惠券、奖品、订单状态、VIP、推广和客服入口，检查路由参数。

**输入校验与异常**

- 昵称为空：提示“昵称不能为空”，不提交。
- 昵称超过 20 个字符：输入限制生效。
- 服务端 401：提示重新登录，不清空页面已有展示。
- 用户数据为空：显示“请登录后查看完整会员权益”或空状态，不展示错误假数据。

### TC-13 我的订单 `pages/orders/index` 与订单详情 `pages/order-detail/index`

**正常操作**

1. 检查“全部 / 待付款 / 待发货 / 待收货 / 已完成”筛选和订单数量。
2. 点击订单商品、查看详情，确认订单号、商品、数量、金额、地址、状态和时间字段对齐。
3. 待付款订单点击支付，进入微信支付参数分支；待收货订单点击确认收货；待付款订单点击取消。
4. 点击商品回到商品详情；点击联系客服进入客服页。

**异常操作**

- 无订单：显示“还没有订单 / 去商城”。
- 订单 ID 不存在：详情显示“未找到该订单”。
- 重复支付、重复取消、重复确认收货：只允许合法状态转换。
- 支付参数缺失、用户取消支付、支付失败：订单状态以服务端查询为准，不显示虚假成功。
- 订单接口 401/500：显示错误提示，不出现半截订单卡片。

### TC-14 我的奖品 `pages/awards/index`

**正常操作**

1. 检查“待兑换 / 已兑换 / 全部”筛选、奖品图片、规格、状态和兑换码。
2. 点击“出示兑换码/查看奖品”，检查展开收起和二维码展示。
3. 点击“查找兑换网点”，进入门店列表；空状态点击“去积分兑换”。

**异常操作**

- 奖品图片或兑换码为空：显示安全占位，不能渲染 `undefined`。
- 已兑换奖品不显示可用核销按钮。
- 奖品接口失败或空数组：显示空状态，不影响门店入口。

### TC-15 推广中心、海报、排行榜、团队

涉及页面：`promotion`、`poster`、`ranking`、`team`。

**正常操作**

1. 推广中心检查邀请码、累计佣金、可提现金额、推广规则、海报、团队、排行榜和佣金记录入口。
2. 点击生成海报，确认商品图片、商品名、价格、二维码和保存按钮。
3. 点击保存海报，检查授权成功、取消授权和保存失败三种分支。
4. 点击分享按钮，检查微信分享面板或开发者工具提示。
5. 排行榜检查排名、头像、昵称、金额和规则入口；团队检查成员数、成员状态和空列表。

**异常操作**

- 推广码接口未登录/失败：提示登录或服务错误，不生成空邀请码。
- 保存图片权限拒绝：提示授权，不崩溃、不重复保存。
- 商品或二维码图片缺失：使用后台配置的占位，不绘制错误 URL。
- 排行榜/团队为空：显示空状态或“0 人”，不出现演示成员混入 API 模式。

### TC-16 客服、规则、记录

涉及页面：`service`、`rules`、`records`。

**正常操作**

1. 客服页分别以 customer、official、channels 参数进入，检查标题和对应内容。
2. 点击订单、门店、优惠券、红包记录入口，确认跳转和筛选类型。
3. 规则页分别验证 coupon、points、campaign、shipping、draw、promotion、ranking 参数，标题和内容对应。
4. 记录页点击积分、优惠券、红包、奖品、佣金和核销记录，检查详情跳转。

**异常操作**

- 视频号未配置：提示“品牌视频号尚未配置”。
- 非微信环境点击在线客服：提示“请在微信小程序中使用在线客服”。
- 记录类型未知或记录 ID 无效：显示空状态，不进入错误页面。

### TC-17 门店核销 `pages/verification/index`

**正常操作**

1. 普通用户进入，确认显示“暂无核销权限”。
2. 员工账号进入，检查门店、扫码核销、手工输入兑换码、待确认奖品和今日核销列表。
3. 扫描有效兑换码或手工输入有效码，检查奖品、规格、领取人、状态和单号。
4. 点击“确认核销”，确认二次确认弹窗；确认后显示“核销成功”，按钮变为已完成核销。
5. 点击核销记录，检查记录详情和分页。

**异常操作**

- 非员工、无权限或无效码：不能看到可核销按钮或提示“未找到奖品，请核对兑换码”。
- 已核销码重复提交：返回幂等结果或明确不可重复核销，不能生成第二条记录。
- 兑换码为空、超长、包含空格：查询前 trim，失败提示清晰。
- 扫码取消、相机权限拒绝、核销接口 409/500：不改变奖品状态。

## 三、跨页面端到端流程

### E2E-01 商品下单

首页 → 商品详情 → 选择规格/数量 → 立即购买 → 选择地址 → 选择优惠券 → 服务端报价 → 提交订单 → 订单详情 → 支付 → 查询订单 → 确认收货。

每一步记录：页面路径、商品 ID、数量、地址 ID、优惠券 ID、订单 ID、接口状态码。中断任一步后返回，重新进入不能丢失已确认状态。

### E2E-02 积分兑换到门店核销

积分专区 → 兑换代金券/实物 → 我的优惠券或我的奖品 → 兑换网点 → 员工核销 → 核销记录。

检查积分扣减、库存扣减、兑换码唯一、核销幂等和后台记录回显。

### E2E-03 扫码奖励

扫码有礼 → 有效码 → 抽奖结果 → 红包/积分/优惠券/奖品 → 我的记录 → 对应详情。

无效码、重复码、取消扫码和接口失败都必须回到可重试页面，不能误发奖励。

### E2E-04 后台配置回显

后台修改商品名称/价格/库存/图片、门店地址、券规则、兑换项、品牌图片和内容 JSON → 刷新服务端 → 重启小程序或重新进入页面 → 检查对应页面逐字段回显。

校验字段：ID、名称、规格、分类、价格（分转元）、库存、状态、排序、图片 URL、跳转页面、规则 JSON、创建/更新时间。后台保存失败时，小程序不得读取半成品数据。

## 四、输入与边界测试表

| 类型 | 测试输入 | 预期 |
| --- | --- | --- |
| 搜索框 | 空、中文、数字、前后空格、特殊字符、超长文本 | 过滤正确，不崩溃，空结果显示空状态 |
| 数量 | 0、1、库存值、库存+1、快速连点 | 最小 1，最大库存，不能负数或超卖 |
| 金额 | 0、整数、两位小数、负数、超大值 | 服务端校验，页面格式化为合法金额 |
| 手机号 | 合法手机号、少一位、多一位、字母、空格 | 仅合法号段通过 |
| JSON | 合法 JSON、空字符串、`{bad`、数组、超长 JSON | 合法保存，非法提示“必须是合法 JSON” |
| ID/查询参数 | 缺失、空串、不存在、特殊字符 | 空状态或回退首页，不白屏 |
| 重复提交 | 同一按钮连续点击 2~5 次 | 只产生一个业务结果 |
| 网络 | 断网、超时、401、404、409、500 | 中文错误提示、保留可恢复状态 |

## 五、后台联调核对

后台每次保存后，必须重新查询列表和详情，再回到小程序核对：

1. 商品：名称、分类、规格、售价、划线价、库存、销量、主图、状态。
2. 门店：名称、城市、区县、地址、营业时间、电话、经纬度、门店图、服务二维码、社群二维码。
3. 优惠券：名称、类型、折扣/金额、门槛、最低数量、渠道、会员限制、有效期、状态。
4. 兑换项：名称、类型、券模板、规格、图片、积分、库存、每人上限、状态。
5. 内容：内容键、类型、标题、副标题、内容 JSON、图片 URL、跳转页、排序、状态。
6. 品牌：首页主图、活动图、地图图、头像、规则 JSON、首页快捷入口 JSON、排行榜 JSON。

## 七、通过标准

- 28 个注册页面均可加载；页面无白屏、崩溃、未捕获异常和明显布局错位。
